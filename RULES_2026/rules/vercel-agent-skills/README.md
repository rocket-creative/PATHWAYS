# Vercel Agent Skills - Installed Skills

This directory contains readable copies of the Vercel agent-skills that have been installed in this project.

## Installed Skills

1. **react-best-practices** - React and Next.js performance optimization guidelines (45 rules)
2. **web-design-guidelines** - UI/UX quality review guidelines (100+ rules)
3. **vercel-deploy-claimable** - Automated deployment creation

## Files

- `react-best-practices-SKILL.md` - Skill definition and quick reference
- `react-best-practices-AGENTS.md` - Full compiled guide with all 40+ rules
- `web-design-guidelines-SKILL.md` - Skill definition
- `vercel-deploy-claimable-SKILL.md` - Deployment skill definition

## Location

Skills are installed at: `.cursor/skills/agent-skills/`

## Usage

These skills are automatically discovered by Cursor and can be used when:
- Reviewing React/Next.js code for performance issues
- Checking UI/UX compliance
- Deploying to Vercel
