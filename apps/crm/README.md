# Pathways Within CRM

Practice management system for Pathways Within — Wisdom and Wellness Collaborative.

## Features

- **Dashboard** — Today's schedule, stats, alerts
- **Patients** — Patient management and profiles
- **Appointments** — Calendar and scheduling
- **Services** — Service catalog management
- **Payments** — Transaction tracking and cash reconciliation
- **Settings** — Account and compliance settings

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Database:** Supabase (coming soon)
- **Payments:** Square (coming soon)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3001](http://localhost:3001)

## Deployment

This app is configured for Vercel deployment:

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel
```
